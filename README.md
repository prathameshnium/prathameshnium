I'm Prathamesh Deshmukh, a physicist working on **multiferroics and magnetoelectric materials**. I build the tools around my experiments: cryogenic sample holders, **Python instrument control** software, and the analysis code for **dielectric spectroscopy**, **electrical transport** and **pyroelectric** measurements.

- **Open to:** postdoc positions in condensed matter or computational physics
- **Contact:** `prathameshnium[at]duck[.]com`
